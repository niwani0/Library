# Free LLM API resources

Condensed pointer to providers offering free or trial-credit LLM API access.
Rate limits and model availability change frequently — this file summarizes
categories only; **always check the live source for current numbers** before
relying on a specific limit:

**Source:** https://github.com/cheahjs/free-llm-api-resources (README is
auto-generated by that repo's `src/pull_available_models.py`; no LICENSE file
is present, so treat it as a reference pointer rather than content to
redistribute further).

## Free tier (no payment required)

- **OpenRouter** — https://openrouter.ai — several `:free`-suffixed community
  and lab models, shared daily/per-minute quota, higher daily cap with a small
  lifetime top-up.
- **Google AI Studio** — https://aistudio.google.com — Gemini Flash/Flash-Lite
  and Gemma models; data used for training if used outside UK/CH/EEA/EU.
- **NVIDIA NIM** — https://build.nvidia.com/explore/discover — various open
  models, phone verification required.
- **Mistral (La Plateforme)** — https://console.mistral.ai/ — free
  "Experiment" plan requires opting into data training + phone verification.
- **Mistral (Codestral)** — https://codestral.mistral.ai/ — code-focused,
  currently free, phone verification required.
- **HuggingFace Inference Providers** — https://huggingface.co/docs/inference-providers/
- **Vercel AI Gateway** — https://vercel.com/docs/ai-gateway
- **OpenCode Zen** — https://opencode.ai/docs/zen/
- **Cerebras** — https://cloud.cerebras.ai/
- **Groq** — https://console.groq.com
- **Cohere** — https://cohere.com
- **GitHub Models** — https://github.com/marketplace/models
- **Cloudflare Workers AI** — https://developers.cloudflare.com/workers-ai

## Trial credits (time- or dollar-limited)

Fireworks, Baseten, Nebius, Novita, AI21, Upstage, NLP Cloud, Alibaba Cloud
(International) Model Studio, Modal, Inference.net, Hyperbolic, SambaNova
Cloud, Scaleway Generative APIs — see the source repo for signup links and
current credit amounts, since trial terms change often.

## When to use this

Point the user at the relevant provider(s) and its live docs link for exact
current rate limits — don't quote specific numbers from memory, since they
drift. If the user wants a specific model with the highest free quota, tell
them to check the source repo's live table rather than relying on a cached
figure.
